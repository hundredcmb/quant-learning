# 申万行业指数 PE-TTM 计算方法（现阶段口径）

本文档描述 `shenwan_industry` 模块**单日排行**新增的行业 PE-TTM 估值列的计算方法。
PE-TTM 属**项目自建口径**（申万官方指数算法文本不含估值章节，见 `AGENTS.md` 第 8 节），
本文件为算法权威描述之一，改动须同步更新 `AGENTS.md` 第 5.1 节。

## 1. 范围与产出

- 仅用于**单日排行**；区间榜（静态 / 官方逐日链式）**不计算** PE（PE 是时点值，区间累计无意义）
- 不区分 `div_kind`（官方价格式 / 分红再投资式）：PE 用当日市值与 TTM 利润，与除息日涨跌幅口径无关
- 每只行业指数（L1 / L2 / L3）提供两种口径（接口/CLI 均返回两列）：
  - **PE-TTM(自由流通)**：自由流通市值口径合成 PE
  - **PE-TTM(总市值)**：总市值口径合成 PE（与新闻/东财常见"行业 PE = Σ总市值 / ΣTTM 利润"同式）
- **Web 主表只有一列「PE-TTM」**，随上方"加权方式"切换口径（总市值/自由流通 → 对应口径；
  等权无定义 → 显示"—"）；CLI 保留两列（一次全打印）
- 无单位、两位小数；行业扣非 TTM 合计 ≤ 0 时显示 **"亏损"**（数据为空时为 **"—"**）
- **Web 排序**：亏损按 PE **最大值**参与排序（降序置顶、升序置底），无数据（"—"）恒置底

## 2. 数据源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 扣非净利润 | `fina_indicator_vip`（**VIP 接口**，需对应积分权限），字段 `profit_dedt` | **年初至今累计值**（非单季值）；单位元；含 `ann_date`（报表公告日）；金额为**归属母公司股东扣非净利润** |
| 自由流通市值 / 总市值 | `daily_basic` 当日全市场（现有涨幅榜同一请求缓存） | 自由流通市值 = `free_share × close`；总市值 = `total_mv`；均单位万元 |

接口明细（参数、分页、数据质量）见 `docs/interface_notes.md` 的 `fina_indicator_vip` 行。

## 3. 每股扣非净利润 TTM

### 3.1 报告期窗口

计算日 D 取**前 24 个月内所有季末**报告期（3/31、6/30、9/30、12/31，最多 8 期），
每期按 `period` 参数一次拉全市场，按报告期在进程内缓存（财务数据仅在财报季变化，跨天复用）。

### 3.2 时点正确性（PIT，按 ann_date 过滤）

每股"最新期" = `ann_date ≤ D` 的最大报告期。回看历史日期（如 2025-04-07）时，
只用当时已公开的财报，消除前视偏差——实测 2025-04-07 当天全市场尚无公司公布
2025 年一季报（最早 2025-04-08），当日全部股票 TTM 落在 2024 年报（或更早年报）。
`ann_date` 缺失时按法定披露截止日保守推定（Q1 → 当年 04-30，中报 → 08-31，
三季报 → 10-31，年报 → 次年 04-30）；实测批量接口 `ann_date` 无缺失。

### 3.3 标准式（主力路径）

```
TTM = 扣非(最新期) + 扣非(去年年报) − 扣非(去年同季)
```

- 因利润字段为**年初至今累计值**，不能直接对多期累计值求和（会放大 2~3 倍）
- 不做"单季差分再求和"：年报经审计、三季报未审计，第四季度单季差分有审计调整误差，
  标准式只用一次加减，与数据商（Wind/东财）一致
- 最新期本身为年报时公式自动退化为"扣非(年报)"

### 3.4 不足四期兜底（年化估算）

当去年年报或去年同季数据缺失（标准式算不出来，典型为新股上市不足约 4 个报告期）：

```
TTM = 扣非(最新期) × 4/k
k = 最新报告期覆盖的季度数（Q1 → 1，中报 → 2，三季报 → 3，年报 → 4）
```

- 例：只有一季度表 → ×4；只有中报 → ×2；只有三季报 → ×4/3
- **系数按最新报告期的累计覆盖季度数 k 确定**（而非数历史报告期个数），
  数据从年初连续上报时两者等价；对"最早报告期为中报"等年中起报情况，按 k=2 缩放更准
  （避免把半年报当"一期"×4 高估一倍）
- 亏损股按 4/k 外推后仍为负值，方向正确，保留参与
- 年化外推是粗略估计（忽略季节性），该类股票多为新股、行业内权重小，属可接受近似

### 3.5 数据质量与缺省

- 同一股票同一报告期接口可能返回**多行**（更新行 + NaN 占位行）：丢弃 `profit_dedt` 为 NaN 的行，
  其余保留最后一条（最新更新）
- 接口对 fields 中**不存在的字段名静默忽略**（不报错），因此取值一律 `getattr` 防御
- 无任何 `ann_date ≤ D` 报告的股票（如上市后首份财报晚于 D、数据缺口）→ 无 TTM，不参与 PE

## 4. 行业 PE 合成

### 4.1 每股贡献（复用当日涨幅榜同一份市值缓存）

当日参与股票池 = 当日行情股票 ∪ 有（过）申万归属的股票，经 `filter_stock_pool` 当日过滤
（与涨幅榜同一套成分/上市/退市/重整规则）；停牌股市值用涨幅榜已解析的**回退市值**（停牌期间
价与股本不变，回退值即当前值），**PE 权重与指数权重严格一致**。

每股 i：

```
free_mv_i  = 自由流通市值(万元)         total_mv_i = 总市值(万元)
ratio_i    = free_mv_i / total_mv_i     （同一日同一行口径下 ≡ free_share/total_share）
profit_wan = 扣非 TTM(元) / 1e4         （统一折算万元）
```

### 4.2 合成公式

```
PE_free  = Σ free_mv_i / Σ (profit_wan_i × ratio_i)   （自由流通市值口径）
PE_total = Σ total_mv_i / Σ profit_wan_i               （总市值口径）
```

- 自由流通口径等价于"以自由流通市值为权重的、个股总市值口径 PE 的**加权调和平均**"
  （`free_mv_i / (TTM_i × ratio_i)` 约分后 = 总市值/TTM，自由流通占比只在权重层起作用）
- 逐股贡献只算一次，L3 → L2 → L1 三级按节点累加（与涨幅榜同构）
- **亏损股（扣非为负）不剔除**：合成法天然让负利润扣减，剔除会系统性高估行业盈利；
  仅三类数据异常剔除：无扣非 TTM / 无市值 / 自由流通占比越界（`ratio > 1`，Tushare 黑盒口径防御）
- 行业扣非 TTM 合计 ≤ 0 → PE 记为"亏损"（`None`）

## 5. 防御与展示约定

- **覆盖率**：参与股票数与当日成分股数可对照（CLI 汇总统计、Web 表格值大小自行对照）；
  剔除告警按原因分类（无扣非TTM / 无市值 / 占比越界）
- **财务接口失败降级**：`fina_indicator_vip` 失败（权限 / 积分 / 网络）时 PE 列全部"—"，
  涨幅排行榜不受影响（警告日志记录原因）——PE 是单日榜"顺带"指标
- **统计输出**（CLI `PE-TTM(扣非)统计` 行 / 日志）：报告期数、标准式股票数、不足四期年化股票数、
  无财报股票数，便于判断当日 PE 质量（年化占比较高时，行业 PE 的可比性下降）

## 6. 性能与缓存

- 每计算日：`fina_indicator_vip` 约 8 期 × 1~2 页（单批 5999 行）≈ 8~16 次请求，
  其余市值/行情全部命中现有缓存；实测 PE 拉取约 6~7 秒、聚合 0.05 秒
- 报告期数据按 `period` 内存缓存（进程内跨日期复用）；TTM 结果按计算日缓存
- 限流：`fina_indicator_vip` 使用独立节流器（7.5 次/秒 ≈ 450 次/分钟，与其它接口互不影响）

## 7. 已知边界

1. **年化估算近似**：不足四期的新股按 4/k 外推，忽略季节性；但仅影响个别行业的小权重成分
2. **自由流通占比黑盒**：`ratio` 依赖 Tushare `free_share` 口径（无扣减明细，见 `known_issues.md` 第 18 条），
   与官方《编制说明》附录二无法逐条核对；`ratio > 1` 极端值按越界剔除
3. **历史日期市值与利润口径**：PE 分母用当日市值、分子用截至当日已披露最新 TTM（时间错配为
   行业 PE 的固有属性）；年报/中报披露季会随大批公司窗口切换出现跳变，属正常
4. **停牌股参与**：停牌股以回退市值参与 PE（与涨幅权重一致），若整段上市期均无市值数据
   则不参与（与加权榜的"仅参与等权榜"不同——PE 无等权口径）
