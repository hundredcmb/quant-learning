# 申万行业指数财务指标计算方法（现阶段口径）

本文档描述 `shenwan_industry` 模块**单日排行**新增的行业财务指标估值列（当前为 **PE-TTM** 与 **PB**）的
计算方法，是财务指标类算法的**唯一权威文档**——未来新增财务指标（如 PS、股息率等）一律写进本文件
（对应分节），并同步更新 `AGENTS.md` 第 5.1 节的指标清单。

所有指标均属**项目自建口径**（申万官方指数算法文本不含估值章节，见 `AGENTS.md` 第 8 节）。

## 1. 范围与产出

- 仅用于**单日排行**；区间榜（静态 / 官方逐日链式）**不计算**估值（时点值，区间累计无意义）
- 不区分 `div_kind`（官方价格式 / 分红再投资式）：估值用当日市值与最新财报数据，与除息日涨跌幅口径无关
- 每只行业指数（L1 / L2 / L3）每个指标提供两种口径（接口/CLI 均返回两列）：
  - **自由流通口径**：以自由流通市值为权重的合成值（等价于"自由流通市值加权的个股总市值口径指标加权调和平均"）
  - **总市值口径**：Σ总市值 / Σ股东值（与新闻/东财常见"行业 XX = Σ总市值 / ΣTTM 利润"同式）
- **Web 主表每个指标一列**，随上方"加权方式"切换口径（总市值/自由流通 → 对应口径；等权无定义 → 显示"—"）；
  CLI 保留每指标两列（一次全打印）
- 显示：无单位/倍率、两位小数；行业股东值合计 ≤ 0 时 PE 显示**"亏损"**、PB 显示**"资不抵债"**（数据为空为"—"）
- **Web 排序**：亏损/资不抵债（null）按最大值参与排序（降序置顶、升序置底），无数据（"—"）恒置底

## 2. 通用约定（各指标共用）

### 2.1 数据源与时点（PIT）

- 财务数据来自 `fina_indicator_vip` **一次批拉同时取多个字段**：`profit_dedt`（扣非净利润）、
  `bps`（每股净资产），同接口、同报告期、同分页（接口明细见 `docs/interface_notes.md`）
- **PIT（消除前视偏差）**：每股取 `ann_date ≤ 计算日 D` 的最大报告期；`ann_date` 缺失按法定披露
  截止日推定（Q1 → 当年 4/30，中报 → 8/31，三季报 → 10/31，年报 → 次年 4/30）
- 报告期窗口 = [D-24 个月, D] 内所有季末（最多 8 期，逐指标复用同一批数据）；按 period 内存缓存
- 市值/股本与涨幅榜同一套当日 `daily_basic` 缓存（含停牌回退值），指标权重与指数权重一致

### 2.2 数据质量（实测）

- 同股票同报告期存在**重复行**：去重为**字段级**独立取最后一条非空值（实测 601318 20260630 两行
  bps 均有效但值不同 56.7800/56.7751，不能整行丢弃；profit_dedt 存在 NaN 占位行）
- `profit_dedt` 为**年初至今累计值**（实测 601318 五期 302.59→735.71→1420.57→1437.73→239.12 亿），
  不是单季值；`bps` 为**报告期末时点值**（平安 51.60→56.78 递增），不是累计值
- 接口对 fields 中不存在的字段名**静默忽略**（不报错），取值一律 `getattr` 防御

### 2.3 合成公式（结构统一）

```
自由流通口径 = Σ 自由流通市值 / Σ (股东值 × 自由流通占比)    自由流通占比 = free_mv / total_mv
总市值口径   = Σ 总市值 / Σ 股东值
```

- 每股"股东值"按指标定义：PE = TTM 扣非净利润（元→万元）；PB = bps × 当日总股本（万元）
- 亏损/负净值股**不剔除**：合成法天然扣减，剔除会系统性高估行业值
- 仅三类数据异常剔除（告警分原因）：无指标数据 / 无市值 / 自由流通占比越界（ratio > 1，Tushare 黑盒口径防御）
- 财务接口失败**整体降级**（该指标列"—"），涨幅榜不受影响——估值是单日榜"顺带"指标

## 3. 指标一：行业 PE-TTM（扣非净利润）

### 3.1 数据与每股 TTM

- 数据：`profit_dedt`（归属母公司扣非净利润，元）
- **累计值口径**（关键）：利润字段为年初至今累计值，禁止对多期累计值直接求和（会放大 2~3 倍）
- **标准式（主力路径）**：`TTM = 扣非(最新期) + 扣非(去年年报) − 扣非(去年同季)`
  （不做单季差分：年报经审计、三季报未审计，公式只做一次加减，与数据商一致；最新期为年报时自动退化为年报值）
- **不足四期兜底（年化估算）**：去年年报或去年同季缺失时 `TTM = 扣非(最新期) × 4/k`，
  k = 最新报告期覆盖的季度数（Q1→1、中报→2、三季报→3、年报→4）；
  系数按"报告期覆盖季度数"而非"历史期数"（年中起报的股票按 k 缩放更准）
- 无任何 `ann_date ≤ D` 报告或利润字段全 NaN 的股票 → 无 TTM，不参与

### 3.2 合成

```
每股股东值(万元) = TTM 扣非(元) / 1e4
PE_free  = Σ free_mv / Σ (股东值 × ratio)      自由流通市值口径
PE_total = Σ total_mv / Σ 股东值                总市值口径
```

## 4. 指标二：行业 PB（每股净资产）

### 4.1 数据与每股净资产

- 数据：`bps`（每股净资产，元）+ 当日 `total_share`（总股本，万股，来自 `daily_basic` 同请求）
- **bps 是时点值、不是累计值** → 无 TTM 滚动、无年化兜底：每股净资产 = `ann_date ≤ D` 最新报告期的 bps
  （新股仅一期也直接用其最新期）
- 每股净资产（万元）= `bps × 当日总股本(万股)`；单股 PB（总市值口径）= 当日总市值 / 净资产 = `close / bps`
- 无 bps 数据（记录缺失 / 字段全 NaN）的股票 → 不参与

### 4.2 合成

```
每股股东值(万元) = bps × total_share(万股)
PB_free  = Σ free_mv / Σ (股东值 × ratio)      自由流通市值口径
PB_total = Σ total_mv / Σ 股东值                总市值口径
```

- 行业净资产合计 ≤ 0 → 显示"资不抵债"（负净资产股不剔除，合成法天然扣减）

### 4.3 口径核对（已实测）

- `单股 PB = close / bps` 与 Tushare `daily_basic.pb` 逐股一致（实测 000001/600036/600519 差 0.0000、
  601318 差 0.0001）；**不使用** `daily_basic.pb` 字段本身——它无法按 `ann_date` 做 PIT（历史日期会把
  以后才披露的净资产混进来），且行业合成需要净资产绝对额而非单股比值

## 5. 防御与展示约定

- 覆盖率：参与股票数与当日成分股数可对照（CLI 汇总统计、Web 表格值大小自行对照）；剔除告警按原因分类
- 统计输出（CLI 每指标统计行 / 日志）：
  - PE：报告期数、标准式 / 不足四期年化 / 无财报股票数
  - PB：报告期数、有净资产 / 无净资产股票数
  - 年化占比（PE）较高时，行业 PE 的可比性下降，以统计行判断

## 6. 性能与缓存

- 每计算日：`fina_indicator_vip` 8 期 × 1 页（单批 9999，实测整批可回 8808 行）≈ **8 次请求**，
  **PE/PB 共享同一批**（二次调用命中缓存零新增请求）；其余市值/股本/行情全部命中现有缓存
- **并发优化**：8 期请求经 `ThreadPoolExecutor(8)` 并发，开始时刻由同一节流器按 7.5/s 错开、
  网络往返并行重叠（同区间行情三池预取的模式）——实测拉取 **~1.4 秒**（串行 ~3.5 秒；
  限速下限即 8×0.133s≈1.07s）；各聚合 ~0.16 秒
- **与计算阶段并行（后台预热）**：单日榜编排在市值拉取完成后即启动后台线程
  （`prefetch_fina_indicators`）预热财务数据，与六条涨幅序列计算并行（接口限流独立、
  只写财务缓存、与市值/股本缓存互不相交）；PE/PB 阶段 join 该线程命中预热缓存——
  拉取的墙体时间被隐藏，失败时 pe/pb 一致降级、不重复拉取
- 浏览器/进程内二次计算同一天 → 报告期缓存命中，该阶段 0 请求
- 报告期数据按 period 内存缓存；每股各期合并按计算日缓存（`_fina_per_stock`）；TTM 与 bps 结果各自按计算日缓存
- 限流：`fina_indicator_vip` 使用独立节流器（7.5 次/秒 ≈ 450 次/分钟，与其它接口互不影响）

## 7. 已知边界

1. **PE 年化估算近似**：不足四期的新股按 4/k 外推，忽略季节性；仅影响个别行业的小权重成分
2. **PB 股本变动近似**：净资产 = 报告期 bps × **当日**总股本——报告期后发生送转/增发/回购时，与
   "报告期股本 × 报告期净资产"略有差异（Tushare 自身 `daily_basic.pb` 同口径，实测逐股一致，可接受）
3. **自由流通占比黑盒**：`ratio` 依赖 Tushare `free_share` 口径（无扣减明细，见 `known_issues.md` 第 18 条），
   与官方《编制说明》附录二无法逐条核对；`ratio > 1` 极端值按越界剔除
4. **历史日期市值与财报口径**：估值分母用当日市值、分子用截至当日已披露最新财报（时间错配为行业估值
   的固有属性）；年报/中报披露季会随大批公司窗口切换出现跳变，属正常
5. **停牌股参与**：停牌股以回退市值/股本参与（与涨幅权重一致），若整段上市期均无市值数据则不参与
