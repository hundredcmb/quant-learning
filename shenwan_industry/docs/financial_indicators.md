# 申万行业指数财务指标计算方法（现阶段口径）

本文档描述 `shenwan_industry` 模块**单日排行**新增的行业财务指标估值列（当前为 **PE-TTM** 与 **PB**）的
计算方法，是财务指标类算法的**唯一权威文档**——未来新增财务指标（如 PS、股息率等）一律写进本文件
（对应分节），并同步更新 `AGENTS.md` 第 5.1 节的指标清单。

所有指标均属**项目自建口径**（申万官方指数算法文本不含估值章节，见 `AGENTS.md` 第 8 节）。

## 1. 范围与产出

- 仅用于**单日排行**；区间榜（静态 / 官方逐日链式）**不计算**估值（时点值，区间累计无意义）
- 不区分 `div_kind`（官方价格式 / 分红再投资式）：估值用当日市值与最新财报数据，与除息日涨跌幅口径无关
- 每只行业指数（L1 / L2 / L3）每个指标提供两种**市值口径**（接口/CLI 均返回两列）：
  - **自由流通口径**：以自由流通市值为权重的合成值（等价于"自由流通市值加权的个股总市值口径指标加权调和平均"）
  - **总市值口径**：Σ总市值 / Σ股东值（与新闻/东财常见"行业 XX = Σ总市值 / ΣTTM 利润"同式）
- 净利润TTM同比（第 5 节）为**单列**：数值%（格式同涨幅列）或类别文本，无市值维度（等权模式也显示）
- PE 在两市值口径之外另有**归母 / 扣非两套利润口径**（后端一次全部算出、共享同一批财务数据零新增请求）：
  接口字段 `pe_ttm_float`/`pe_ttm_total`（归母）与 `pe_ttm_deducted_float`/`pe_ttm_deducted_total`（扣非）；
  **CLI 打印的 PE 两列为归母口径**
- **Web 主表每个指标一列**，随上方"加权方式"切换市值口径（总市值/自由流通 → 对应口径；等权无定义 → 显示"—"）；
  **PE 列另随"净利润口径"下拉切换归母/扣非**（默认归母，PB 与该下拉无关）；成分股子表个股 PE 同样双口径切换
  （`pe_ttm`/`pe_ttm_deducted`）；CLI 保留每指标两列（一次全打印）
- 显示：无单位/倍率、两位小数；行业股东值合计 ≤ 0 时 PE 显示**"亏损"**、PB 显示**"资不抵债"**（数据为空为"—"）
- **Web 排序**：亏损/资不抵债（null）按最大值参与排序（降序置顶、升序置底），无数据（"—"）恒置底

## 2. 通用约定（各指标共用）

### 2.1 数据源与时点（PIT）

- PE 数据来自 `fina_indicator_vip` **一次批拉同时取多个字段**：`profit_dedt`（扣非净利润）、
  `extra_item`（非经常性损益，自带正负号）与 `bps`（每股净资产），同接口、同报告期、同分页
  （接口明细见 `docs/interface_notes.md`）
- 归母净利润另有**业绩快报（`express_vip`）提前可用源**（见第 3.1 节双源合并规则）；扣非与 bps 无快报源
- PB 数据来自 `balancesheet_vip` 按报告期批拉：**PB 分母 = `total_hldr_eqy_exc_min_int`（归母权益）
  − `oth_eqt_tools`（其他权益工具，合计、已含优先股；子项 `oth_eqt_tools_p_shr` 不可重复扣减）
  = 归属于母公司普通股股东的权益（绝对额元、报告期末时点值）**——与 `bps` 分子**严格同口径**
  （实测 20250407 对账：招行 12260−1804=10456 亿 == bps×当日股本分毫不差；宁波银行 2332−248=2084 亿
  ≈ bps×股本 2082 亿，0.1% 为可转债转股漂移；华能/东航/大唐/深能源等永续债大户隐含股本与当日总股本
  吻合 0.001%），与 Tushare `daily_basic.pb` 及数据商惯例一致（普通股总市值对应普通股股东权益）
- **归母净利润不在该接口**（利润表接口才有归母绝对额，实测本接口请求 `n_income_attr_p` 被静默忽略），
  由恒等式**行内合成**：`归母 = profit_dedt + extra_item`。全市场实测（20250630）：可对齐 6243 只、
  **99.8% 相对误差 <0.1%（P95≈2e-16 浮点精度级）**、有扣非时 extra 缺失率 0%；仅同行两字段齐备
  才算出，否则该行归母=None，**不跨行拼接**（宁缺勿猜，由无财报统计兜底）
- **PIT（消除前视偏差）**：每股取 `ann_date ≤ 计算日 D` 的最大报告期；`ann_date` 缺失按法定披露
  截止日推定（Q1 → 当年 4/30，中报 → 8/31，三季报 → 10/31，年报 → 次年 4/30）
- 报告期窗口 = [D-24 个月, D] 内所有季末（最多 8 期，两池共用 `_fina_period_window`）；按 period 内存缓存
- 市值与涨幅榜同一套当日 `daily_basic` 缓存（含停牌回退值），指标权重与指数权重一致（PB 不再用股本）

### 2.2 数据质量（实测）

- 同股票同报告期存在**重复行**：去重为**字段级**独立取最后一条非空值（实测 601318 20260630 两行
  bps 均有效但值不同 56.7800/56.7751，不能整行丢弃；profit_dedt 存在 NaN 占位行；归母合成在
  字段级去重**之前、按行内值**进行，不跨行拼凑）
- 利润字段为**年初至今累计值**——`profit_dedt` 与合成后的归母均是（实测 601318 五期
  302.59→735.71→1420.57→1437.73→239.12 亿），不是单季值；`bps` 为**报告期末时点值**
  （平安 51.60→56.78 递增），不是累计值
- 接口对 fields 中不存在的字段名**静默忽略**（不报错），取值一律 `getattr` 防御

### 2.3 合成公式（结构统一）

```
自由流通口径 = Σ 自由流通市值 / Σ (股东值 × 自由流通占比)    自由流通占比 = free_mv / total_mv
总市值口径   = Σ 总市值 / Σ 股东值
```

- 每股"股东值"按指标定义：PE = TTM 归母净利润（元→万元）；PB = 归母普通股股东权益（元→万元）
- 亏损/负净值股**不剔除**：合成法天然扣减，剔除会系统性高估行业值
- 仅三类数据异常剔除（告警分原因）：无指标数据 / 无市值 / 自由流通占比越界（ratio > 1，Tushare 黑盒口径防御）
- 财务接口失败**整体降级**（该指标列"—"），涨幅榜不受影响——估值是单日榜"顺带"指标

## 3. 指标一：行业 PE-TTM（归母净利润）

### 3.1 数据与每股 TTM

- 数据：**归母净利润 = `profit_dedt + extra_item` 行内合成**（元，恒等式与实测覆盖率见第 2.1 节；
  接口无归母绝对额字段）——归母口径是"市价 ÷ 盈利"的通用定义（新闻/数据商行业 PE 均用归母）
- **业绩快报双源 PIT 合并（2026-08-27 新增，`_merge_attr_with_express`）**：报告期值若快报
  （`express_vip.n_income`，即归母净利润、未审计初步数）发布更早，则年报披露前以快报值参与——
  合并可用日 = min(财报日, 快报首版日)（"最新期"按此选取）；值优先级 = **审定优先**（fina 已可用
  且归母非空用 fina，否则快报 ann_date ≤ D 的最新修正版本；fina 可用但归母为 None 也回退快报）；
  TTM 三期各自独立解析；快报池失败退回纯财报口径（仅告警）。实测口径与量级：快报与审定值中位差
  ~0.7%、43% 差 >1%、~10% 差 >10%（减值/公允价值等审计时才定）；2025-04-07 快报参与 1060 只
  （年报未披露而快报已出，最新期从 Q3 提前到年报）；stats 加
  `stocks_express`（CLI 统计行打印"快报参与 N 只"）
- **扣非口径（`get_ts_code_to_ttm_deducted_profit`）**：与归母同批数据、同规则一次全部算出
  （换字段不换算法），Web"净利润口径"下拉可切换显示（默认归母，CLI 的 PE 列固定归母）
- **累计值口径**（关键）：利润字段为年初至今累计值，禁止对多期累计值直接求和（会放大 2~3 倍）
- **标准式（主力路径）**：`TTM = 归母(最新期) + 归母(去年年报) − 归母(去年同季)`
  （不做单季差分：年报经审计、三季报未审计，公式只做一次加减，与数据商一致；最新期为年报时自动退化为年报值）
- **不足四期兜底（年化估算）**：去年年报或去年同季缺失时 `TTM = 归母(最新期) × 4/k`，
  k = 最新报告期覆盖的季度数（Q1→1、中报→2、三季报→3、年报→4）；
  系数按"报告期覆盖季度数"而非"历史期数"（年中起报的股票按 k 缩放更准）
- 最新期归母合成失败 → 按无财报处理（stocks_missing 统计），不回看更早期
- 无任何 `ann_date ≤ D` 报告或利润字段全 NaN 的股票 → 无 TTM，不参与

### 3.2 合成

```
每股股东值(万元) = TTM 归母(元) / 1e4
PE_free  = Σ free_mv / Σ (股东值 × ratio)      自由流通市值口径
PE_total = Σ total_mv / Σ 股东值                总市值口径
```

## 4. 指标二：行业 PB（归母普通股股东权益）

### 4.1 数据与每股净资产（2026-08-27 改为权威绝对额）

- 数据：`balancesheet_vip` 的 **归母普通股股东权益绝对额**（`归母权益 − 其他权益工具` 行内合成，
  恒等式与对账证据见第 2.1 节；`get_ts_code_to_equity`）——**不经"每股×股本"折算**
- **净资产是报告期末时点值、不是累计值** → 无 TTM 滚动、无年化兜底：每股净资产 = `ann_date ≤ D`
  最新报告期的普通股东权益（PIT 规则与 PE 完全一致；新股仅一期也直接用其最新期）
- 单股 PB（总市值口径）= 当日总市值 / 归母普通股股东权益
- 无数据（`balancesheet_vip` 记录缺失 / 字段全 NaN）的股票 → 不参与
- **为什么改**：旧口径 `bps × 当日总股本` 把"报告期每股净资产"乘上"当日股本"，在两处股本口径
  不一致时出错（实测全市场 20250407 差异 >5% 的 231 只）：送转/增发/回购窗口（bps 分母为报告期
  股本、当日股本已变，如国泰君安/国联证券吸收合并增发、中钨高新发行股份购买资产——旧口径高估
  净资产最多 2 倍）、CDR（九号公司 `bps` 分母与 `daily_basic` 总股本差 10×，旧口径 PB 低估 10 倍）、
  次新 bps 分母漂移（302132 差 4.5×）；绝对额口径天然免疫。旧路径 `get_ts_code_to_bps`
  （bps×当日股本）保留作对照

### 4.2 合成

```
每股股东值(万元) = 归母普通股股东权益(元) / 1e4
PB_free  = Σ free_mv / Σ (股东值 × ratio)      自由流通市值口径
PB_total = Σ total_mv / Σ 股东值                总市值口径
```

- 行业净资产合计 ≤ 0 → 显示"资不抵债"（负净资产股不剔除，合成法天然扣减）

### 4.3 口径核对（已实测）

- 新旧口径对账（20250407 全市场）：567/998 个行业值与旧口径一致到 0.01%（普通股东权益与 bps 分子
  同口径的直接证据）；差异集中在上述股本错配个股（其他运输设备 +369% 即九号公司 CDR 修复、
  钨 +18~21% 即中钨高新增发修复、证券Ⅲ +7.9% 即吸收合并窗口修复）
- 旧 `单股 PB = close / bps` 曾与 Tushare `daily_basic.pb` 逐股对照一致（000001/600036/600519 差
  0.0000、601318 差 0.0001，见 `known_issues.md` 第 37 条①）；**不使用** `daily_basic.pb` 字段本身——
  它无法按 `ann_date` 做 PIT（历史日期会把以后才披露的净资产混进来），且行业合成需要净资产绝对额
  而非单股比值

## 5. 指标三：行业净利润TTM同比（归母口径）

### 5.1 数据与口径（2026-08-27 新增，列名"净利润TTM同比"）

- 个股：`增长 = TTM(D) / TTM(D-1年) − 1`，两期均走归母 TTM 机制（含业绩快报双源合并、PIT、
  4/k 兜底——与 PE 分子完全同源）；基期 = 同日历日去年（2/29 回退 2/28），报告期窗口自动落到
  [D-36 月, D-12 月]，预热在主日期之后串行补拉（共享报告期命中 period 缓存，实测仅多 4 期
  +8 次请求；2022~2023 旧报告期行数触顶 9999 自动翻页各 2 页）
- 行业：`Σ TTM(D) / Σ TTM(D-1年) − 1`（与 PE 的 Σ市值/Σ股东值 同构；亏损股不剔除、负值参与
  合计，扭亏/转亏个股的贡献自动进入 Σ）
- **参与 = 两期 TTM 均有的成分股（both-or-neither）**：缺基期的新股（上市不满约一年半）不进
  分子也不进分母（只进分子会系统性抬高增速），计入 stats `stocks_no_base`
- 基期为"当前快照回看"：含基期日之后发布的财务更正（与 PE 历史回看同口径，见 known_issues 第 39 条）
- **归母/扣非双口径（2026-08-27）**：`profit_kind` 参数化，两口径一次算出、共用已拉报告期数据
  零新增请求，Web 随"净利润口径"下拉切换（接口字段 `profit_growth`/`profit_growth_deducted`）；
  扣非无快报源——年报季（1~4 月）扣非增长时效落后归母一档；**类别两口径独立判定**（归母扭亏
  而扣非持续亏损真实存在——非经常性收益保壳，实测 20250407 两口径类别不一致 631 只、扣非
  持续亏损 1318 只 vs 归母 1055 只）

### 5.2 显示与排序（个股与行业同一规则）

| 显示 | 条件（当期/基期） | 排序位 |
|---|---|---|
| 数值 ±xx.xx% | 两期均 >0，∈[−100%, ∞) | 中间，数值升序 |
| 扭亏 | 当期 >0、基期 ≤0 | 最高（高于一切数值） |
| 转亏 | 当期 ≤0、基期 >0 | 低于一切数值 |
| 持续亏损 | 两期均 ≤0 | 最低 |
| — | 无数据（键缺失） | 恒置底 |

- 数值格式同"涨幅"列（带符号、两位小数、%）；**仅数值着色**（红涨绿跌同涨幅列），
  类别文本（扭亏/转亏/持续亏损）与无数据不着色；扭亏类比值无定义（负基数），类别化恰好避免
  微利基数股以 +4000% 霸榜；数值不封顶（极端低基数真值照显，例见第 8 节）
- Web 排序经 `growthSortValue` 把类别映射为 ±1e12 哨兵数值进入通用比较器

### 5.3 统计

- `stocks_pair`（参与）/ `stocks_turnaround`（扭亏）/ `stocks_turnloss`（转亏）/
  `stocks_continued_loss`（持续亏损）/ `stocks_no_base`（当期有基期无）/ `pool_no_value`（池内
  无增长对）；CLI 统计行全量打印（实测 20250407：参与 6248、扭亏 341、转亏 569、持续亏损 1055、
  无基期 180、池内无数据 19）

## 6. 防御与展示约定

- 覆盖率：参与股票数与当日成分股数可对照（CLI 汇总统计、Web 表格值大小自行对照）；剔除告警按原因分类
- **成分股子表**（Web 单日榜）：每只成分股也带 PE-TTM/PB 列——个股**总市值口径**（与行业总市值口径公式一致：
  PE = 总市值/(TTM 归母)，PB = 总市值/归母普通股股东权益），财务缓存命中零请求；亏损/资不抵债/缺失的
  显示与行业列一致（"亏损"/"资不抵债"/"—"）；区间榜成分股子表不带这两列
- 统计输出（CLI 每指标统计行 / 日志）：
  - PE：报告期数、标准式 / 不足四期年化 / 无财报股票数
  - PB：报告期数、有净资产 / 无净资产股票数

## 7. 性能与缓存

- 每计算日：`fina_indicator_vip` 12 期（当期 8 + 增长基期新增 4，**旧报告期触顶 9999 各翻 2 页**）+
  `balancesheet_vip` 8 期 + `express_vip` 12 期 ≈ **36 次请求**（实测 fina 16 / bs 8 / express 12）；三池各自二次调用命中缓存零新增
  请求，其余市值/行情全部命中现有缓存
- **并发优化**：每池 8 期请求经 `ThreadPoolExecutor(8)` 并发，开始时刻由**各自节流器**按 7.5/s
  错开、网络往返并行重叠（同区间行情三池预取的模式）；**各池之间也并行**（接口限额独立）
  ——实测多池并行总墙时 **~1.4~1.5 秒**（与单池同量级、不串行叠加；串行 ~3.5 秒；
  限速下限即 8×0.133s≈1.07s）；各聚合 ~0.03 秒
- **与全部计算阶段并行（后台预热）**：单日榜编排在**最开始**即启动后台线程
  （`prefetch_fina_indicators`：fina/bs/express 三池并行拉取），与六条涨幅序列计算并行
  （接口限流独立、只写各自财务缓存、与市值缓存互不相交）；PE/PB 阶段 join 该线程命中预热
  缓存——拉取的墙体时间被隐藏；任一池失败仅该池对应指标降级（bs 池失败只影响 PB）
- 浏览器/进程内二次计算同一天 → 报告期缓存命中，该阶段 0 请求
- 报告期数据按 period 内存缓存；每股各期合并按计算日缓存（`_fina_per_stock`/`_bs_per_stock`）；
  TTM / bps / equity 结果各自按计算日缓存
- 限流：`fina_indicator_vip` 与 `balancesheet_vip` 与 `express_vip` 各用独立节流器（7.5 次/秒 ≈ 450 次/分钟，互不影响）

## 8. 已知边界

1. **PE 年化估算近似**：不足四期的新股按 4/k 外推，忽略季节性；年化占比高的行业（次新集中）
   PE 可比性下降，以 CLI 统计行判断，仅影响个别行业的小权重成分
2. **PB 股本近似已消除（2026-08-27 改权威绝对额）**：旧口径"报告期 bps × 当日总股本"在送转/
   增发/回购/CDR/次新场景引入比例级偏差（清单见第 4.1 节），已改为 `balancesheet_vip` 归母普通股
   股东权益绝对额；残余近似仅为"报告期后到当日的利润累积/分红未反映"——这是所有财报频率 PB 的
   固有 staleness（数据商同样存在）
3. **自由流通占比黑盒**：`ratio` 依赖 Tushare `free_share` 口径（无扣减明细，见 `known_issues.md` 第 18 条），
   与官方《编制说明》附录二无法逐条核对；`ratio > 1` 极端值按越界剔除
4. **历史日期市值与财报口径**：估值分母用当日市值、分子用截至当日已披露最新财报（时间错配为行业估值
   的固有属性）；年报/中报披露季会随大批公司窗口切换出现跳变，属正常
5. **停牌股参与**：停牌股以回退市值参与（与涨幅权重一致），若整段上市期均无市值数据则不参与
6. **balancesheet_vip 覆盖差**：北交所（430xxx）与部分次新缺行（20241231 期较 fina 少 259 只），
   均不在申万股票池内、池内剔除数实测零变化；两接口"最新期"偶有不同步（20250407 实测 9 只，
   PIT 回退到不同期）；偶见畸形代码（`833243!1.BJ`）不匹配任何股票池，无害
7. **业绩快报为未审计初步数**：精度损失、覆盖范围与"扣非无快报源"的时效不对称均见第 3.1 节 /
   第 2.1 节；快报窗口内（年报季 1~4 月）单股 PE 会随快报修正/年报审计结果跳变——属 PIT 本义
   （当时市场看到的也是快报数）
8. **净利润TTM同比边界**：基期为"当前快照回看"（含此后更正，与 PE 历史回看一致）；本期标准式与
   基期 4/k 年化混用的股票同比略失真；低基数行业出现极端百分比（实测社会服务 +955%、航海装备
   +1151%，2024 vs 2023 真实低基数）不封顶照显
