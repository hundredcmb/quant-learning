# 申万模块：已知边界与易错点

本文件为 `shenwan_industry/AGENTS.md` 的子文档，汇总模块已知边界与易错点（共 41 条，均经实测验证或代码确认）。涉及本模块任务时，改动前后请对照本清单确认未破坏既有行为。

1. 涨跌幅口径见 `shenwan_industry/AGENTS.md` 第 3 节；改动时必须保持该口径，或明示切换为全收益口径
2. 停牌股等权按 0% 计入平均、加权按 0% 涨幅 + 停牌前自由流通市值计入分母；停牌占比高的日期，等权涨幅会被系统性拉低
3. 停牌自由流通市值回退（新策略默认，机制详见 `AGENTS.md` 第 5 节）：`new` 模式每股先近 730 天（limit 阶梯 1→100 行、响应按交易日降序）再全窗回到上市日（19900101 起），**尽量不放弃任何股票**（仅整个上市期无 `daily_basic` 数据才跳仅等权榜并告警），仅字段缺失/非正行向前找正常行（`free_share>float_share` 比例越界行视为 Tushare 正常口径直接采信——2026-08-23 策略调整，实测 001216 比例 1.43）；旧 730 天上限经 `SW_MV_RESOLVE_MODE=legacy` 保留供对比；逐股回退由 `resolve_missing_mv` 线程池（`MV_RESOLVE_WORKERS=8`）并发补齐（实测区间首查 mv 阶段 18.6s → ~2s）；"批回填"方案实测冗余/更差，已移除
4. 上市首日（`list_date == date`）不参与，`list_date >= date` 即剔除
5. 退市股/暂停股在成分股加载时已纳入（`stock_basic` L/D/P），按 `delist_date` 截断；`stock_basic` 每次调用不分页，若单次行数上限低于对应状态股票总数会漏尾部股票（当前 L=5543 未触发，扩容后有风险）
6. `no_industry_stocks` 在 tree 实例上累积，后续日期过滤会一直沿用
7. `MarketDataProvider` 内存缓存按日期键分开；同一实例跨日期复用不会串数据（停牌回填值也写在对应日期字典里）
8. 非交易日 `daily` 返回空 → 排名方法抛 `ValueError`
9. NaN/缺失值防御（已加固）：`pre_close`/`close` 缺失、为 0 或非有限值时 `get_ts_code_to_pct_chg` 记为 None 并告警，排名时该股票不计入平均/加权（不再污染 NaN）；自由流通市值三字段缺失/为 0/非有限时该股不记入（等同无市值），缺失时走停牌回退，回退扫描同样跳过缺失/非正行（公式与 `free_share>float_share` 采信规则见 AGENTS.md 第 3/5 节）；`stock_basic` 的 `list_date` 为 NaN/None 时跳过（不再 `strptime` 崩溃）
10. 复权字段单位（已实测验证）：tushare `dividend` 的 `stk_div` 为每股送转股数（10送10 → 1.0）、`cash_div` 为每股派现元（10派10 → 1.0）；`adj_factor` 与 `daily.pre_close` 同属**除权参考价（价格）口径**，比值收益 = close/除权参考价 − 1，现金分红不计入收益；曾被独立实现的"送转除、派现减"静态前复权算法（原 `qfq_adjust.py`，已删除）与上述口径一致
11. 停牌复牌（已实测验证）：`daily` 在停牌日**没有记录**；普通复牌日 `pre_close` = 停牌前最后收盘价（实测 300862/300955），停牌期间发生除权除息时复牌日 `pre_close` = 交易所发布的除权参考价，因此复牌日涨跌幅直接用 `close/pre_close` 即为交易所口径，无需额外处理
12. **除权参考价可能不是"免费送转"公式**（000793.SZ 实测案例）：*ST华闻 2026-06-22 复牌日为重整计划"有偿转增"（10转12，转增平均价格 2.41 元/股），交易所除权参考价 = (前收 2.63 + 2.41×1.2)/(1+1.2) = **2.51**，而非普通免费送转的 2.63/2.2≈1.20；`dividend` 接口只含转增比例、不含转增价格，**无法自行推导除权参考价**；第三方"不复权"行情（如东财显示 0.38%）未采用交易所参考价，与官方口径（Tushare `pct_chg` 5.18%）不同。**结论：当日涨跌幅/昨收一律以 `daily.pre_close`（交易所口径）为准，`dividend` 只用于了解方案本身**
13. 历史成分口径（已修）：排名按 `index_member_all` 的 Y(当前)+N(历史退出) 拼成每股完整 in/out 区间（`ts_code_membership`，date-aware，见 AGENTS.md 第 2 节）并按分析日过滤/归属，已消除"未来纳入""历史退出""退市股被整体剔除"三类偏差；**已知数据质量问题（实测）**：L3 `in_date` 存在回填不一致（顺丰 L3"快递"in_date=20100323 早于 L1 切换日 20170303）、借壳换代码股票（三六零 601313→601360）历史挂在现代码下、2021-12-13 前后有版本切换记录（中免、中公）——历史区间以 SW2021 代码口径回填、与当时官方版本可能不完全一致（见第 23 条）；已从申万彻底移除（无 Y/N 记录）的股票无法解析历史归属
14. 区间榜口径（静态版；官方逐日链式见第 32 条）：参与/剔除规则与首日盘前市值权重锚定见 AGENTS.md 第 7 节；补充——整段无行情（整段停牌）的股票不参与；无法取到**首日盘前市值**的股票仅参与等权榜（告警不中断）；**区间收益包含起始日当天涨跌**（隐含基准 = 首个有行情日的 `pre_close`），单日区间（起止同日）等于当日涨跌幅（加权权重为盘前口径，与单日榜 reinvest 式一致）
15. 性能约定：DataFrame 逐行遍历统一使用 `itertuples(index=False)`（实测 5500 行 × 66 天解析：`iterrows` 约 5.7s vs `itertuples` 约 0.1s），不要改回 `iterrows`；行内取值用 `row.列名`（可选列用 `getattr(row, '列名', None)`），转 dict 用 `row._asdict()`
16. `sw_daily` 字段单位（已实测验证，官方文档确认）：`amount` 为**万元**、`vol` 为**万股**（非元/手），后端透传不改单位；前端 `formatAxisMax` 按"万"为单位解释（≥1e4 显示亿、≥1 显示万、<1 显示元数字），`formatAmount` 为 万元÷1e4→亿元，`formatVolume` 直接以"万股"标注——改动前端单位换算前先确认输入单位
17. 行业指数 K 线（前端约定）：**仅行业名称列可点击**（代码列不响应点击），数据来自 Tushare `sw_daily`、前端本地 ECharts 绘制，副图支持成交额/成交量切换；L1 全覆盖、L2/L3 仅官方指数有日线数据的行业可点击（实测 L2 124/134、L3 259/346 有数据），无官方日线的行业保持纯文本（不提示"无指数"）；可用性探测机制（`sw_daily` 按最新交易日全市场一次拉取与 `data/SW2021.json` 求交集、**服务启动时后台探测一次并内存缓存**（无文件缓存，`service.prebuild_sw_daily_available`）、前端在探测完成前等待就绪最多 30 秒）见 `docs/interface_notes.md` 的 `sw_daily` 行；探测失败时回退为仅 L1 可点击
18. **自由流通口径无法与官方附录二核对（已知边界，不可核实）**：官方《编制说明》附录二定义六类非自由流通扣减（国有股、法人股、管理层持股、职工股、其他受限股、特殊情况，正文已录入 `Shenwan_Index_Series_Algorithm_Text.md` 附录二）；但唯一数据源 Tushare `daily_basic` 只返回 `free_share`（自由流通股本）、`close`（收盘价）等**最终结果**（黑盒、无扣减明细），无法（也不需要）逐条核对；项目以 Tushare 口径为准（`free_share × close`，见 AGENTS.md 第 3 节），两者是否完全一致无从验证，属可接受的已知边界，后续同步工作不再要求对齐附录二名目
19. **公司停牌一律按一般停牌处理（有意取舍）**：停牌按 0% 涨幅、停牌前自由流通市值计入加权分母（见 AGENTS.md 第 5 节）；官方 4.4.10 的「股改公司复牌首日退出指数、复牌后第 2 个交易日重新计入」**不再需要区分**——若发生由官方成分断点自动覆盖，机制与"断点即是否股改的标识"详见第 29 条；一般停牌本身与官方 4.4.10 一致（已对照，见 `docs/sync_progress.md` 4.4.10）
20. **送转股股本在除权日当天即更新（已实测验证）**：`daily_basic` 的 `total_share`/`float_share`/`free_share` 在**除权日（ex_date）当天**即按送转比例更新（实测 301261.SZ 10转2 → `free_share` 精确 ×1.2000；603400.SH 10转3+派0.3 → ×1.294，Tushare 按实际登记股本），A 股红股上市日（`div_listdate`）＝除权日；官方 4.4.4 面向「股本滞后到上市日」的「除权日至上市日 / 上市日」两阶段在 A 股 `daily_basic` 中不出现（扫 2026-06~07 全部除权日，唯一「上市日晚于除权日」样本 200028.SZ 为 B 股、不在 A 股 daily_basic 内），故项目靠 `M=p_t·q_t`（当日股本已含送转）+ `pre_close` 除权参考价口径自洽即可，无需实现送转滞后阶段；对照结论见 `docs/sync_progress.md` 4.4.4（捆绑派现的价格口径差异见 AGENTS.md 第 3 节）
21. **`circ_mv` 与 `free_share`/`float_share` 在股本变动窗口可能不同步（已实测验证，建议固化用 `free_share × close`）**：正常情况下 `daily_basic.circ_mv = float_share × close` 精确成立（逐日核对比例恒 1.0）；但非分红类股本变动时（实测 300806.SZ：20260717 `float_share`/`free_share` 突发 +1041.30 万股，0717~0724 窗口内），`circ_mv` 仍按变动前旧基数计算（`circ_mv/close` ≈ 旧 `float_share`），该窗口 `circ_mv/(float_share×close)≈0.968`、旧式 `circ_mv×free_share/float_share` 与新式 `free_share×close` 相差约 3.3%；**结论：自由流通市值一律用 `free_share × close`（与当日报告股本自洽、即官方「自由流通量×市价」），勿改用 `circ_mv` 派生，避免继承其更新滞后**
22. **非自由流通股上市流通按 free_share 实际日计入；规则②为时点近似已知边界（2026-08-24 更新）**：官方 4.4.13 的市值调整公式（分母按 t-1 价×t 日新股本回填）与规则①「上市日计入」（＝ `free_share` 更新日）项目已天然一致（`M/M_pre` 自洽，见 `docs/sync_progress.md` 4.4.13）；**公式层两条规则同一公式、均已一致**。规则②「公告日（非交易日顺延）+第 4 交易日」对债转股/权证行权/定向回购**提前**计入新增自由流通量——官方按公告日+4交易日使用新 q、项目按 `daily_basic` 数据实际报告日（两者公式恒等、仅 q 生效时点不同）：`share_float` 仅覆盖限售股解禁（实测 2026-06~07 共 72,565 条解禁记录**全为规则①型**，0 条规则②型）、债转股等事件类型无统一接口，时点窗口（公告日~Tushare 更新日）存在但影响可忽略（与 4.4.6 债转股"数据实际报告日"近似同构）→ 记 ⏳ 已知边界。另实测：301503.SZ 解禁日 `free_share` 不变（解禁给大股东按附录二仍属非自由流通，不能拿解禁量直接加入 q）；300806.SZ 0717 `free_share` 突跳并非解禁（当天 36 条解禁无它），说明存在 share_float 之外的股本变动。**结论：以 `free_share` 实际变化为准即最忠实，不构建显式事件表**
23. **历史归属按 SW2021 口径回填 + 区间榜中途换行业简化 + 市值回退不放弃（已知边界）**：① 历史区间按当前 SW2021 代码回填（`index_member_all` Y+N，数据质量注意点见第 13 条），不做双版本支持；② 区间榜聚合锚定起始日行业，区间内跨行业切换不按天分段归属（单节点模型延续，见 `docs/sync_progress.md` 4.4.1/4.4.2；**逐日归属已由官方逐日链式区间榜实现**，见第 32 条）；③ 市值回退默认回到上市日（超 2 年停牌也能解析、不放弃任何股票），旧 730 天逻辑经 `SW_MV_RESOLVE_MODE=legacy` 保留作对比（见第 3 条 / AGENTS.md 第 5 节）。实测：单日榜 2019-12-31 可跑通且 0 放弃；跨 2021-06-11 行业切换的区间会正确剔除 000004.SZ 等换出股票（`left_mid_range`）
24. **公司退市口径已同步（官方成分 out_date=整理期首日，2026-08-24 更新）+ 新股第 6 交易日已同步**：官方 4.4.3 退市=成分退出（参照 4.4.2），退出日为摘牌日或**退市整理期首日**。实测 2025-01 以来全部 50 只退市股 `index_member_all`：**26 只含整理期的 out_date 精确=整理期首日**（与 `namechange`「XX退」改名日逐一吻合）、**19 只无整理期**（创业板/科创板/吸收合并）out_date=摘牌日、3 只无成分记录（北交所/数据缺口）→ 项目 `not_member`（out_date≤当日）**在整理期首日起自动剔除**、`delisted`（delist_date=摘牌日）兜底，与官方一致，"整理期官方已剔除、项目仍计入"的差异窗口不存在（原"Tushare 无整理期首日字段"顾虑消除——官方成分 out_date 即字段）。**新股「上市第 6 个交易日才纳入」已同步**（`filter_stock_pool.not_listed` 以 `list_date` 起计交易日，`trade_cal` 精确计数，见 AGENTS 第 2 节）；注意 Tushare 新股 `index_member_all.in_date` 可能早于上市日（实测 301655 in_date=20260731 < list=20260820；部分北交所新股无 index_member_all 记录），6 日门槛**必须以 `list_date` 为准**。对照见 `docs/sync_progress.md` 4.4.3
25. **配股靠 pre_close 自动处理，权重锚定 free_share（德赛实测）**：官方 4.4.5 配股无需项目显式编码——`daily.pre_close` 在配股除权日返回交易所配股除权参考价 `P_ref=(前收+配股价×比例)/(1+比例)`（实测 000049.SZ：股权登记日 2023-11-29 收 31.54 → 复牌除权日 12-08 pre_close=29.24，反推 10 配 2.85…/配股价约 21.2 吻合），单股涨幅 `(p_t−P_ref)/P_ref` 与官方恒等（q 抵消）。**权重层边界**：配股新股落控股方时不进 `free_share`（德赛 free_share 全程恒定 20955.1，`float_share` 至上市日 12-25 才 +8525 万股）——项目锚定 Tushare `free_share`（附录二扣减后的真实自由流通量）即官方附录二口径，与官方文本机械 ×(1+m/10) 存在张力（官方文本在该情形会高估自由流通量）；`free_share` 未在除权日含新股本时，与官方"除权日即计入 (1+m/10) 权重"差一个缴款期窗口、配股罕见、影响可忽略。对照见 `docs/sync_progress.md` 4.4.5
26. **债转股（可转债转股）无需显式编码，free_share 批量转股时可能滞后数日（利柏实测）**：官方 4.4.6 债转股不除权、只更新股本/自由流通量；项目靠 `daily_basic` 股本自动捕捉 + `M/M_pre` 价值中性（q 抵消、价格用前收），转股日无虚假涨幅，无需改代码——实测利柏特 605167.SH/转债 111023.SH：转股股本分批跳（总股本 0604+1124 万、0612+3863 万、0625+1094 万），跳股本日 `pre_close`=前收（不除权）。**数据时点边界**：批量转股时 `free_share` 可能滞后总股本数日（实测 0612 总股本 +3863 万 → free 0617 才 +3863 万），期间项目按旧自由流通量、短暂低估该股权重（约 7.7%、5 天）；官方 4.4.6「公告日 t2+1 生效」与 Tushare 更新日不逐日对齐，项目取「数据实际报告日」为合理近似。Tushare 有可转债接口（`cb_basic`/`cb_issue`/`cb_share` 转股结果/`cb_call` 赎回/`cb_price_chg`），可核对，但项目不需要。对照见 `docs/sync_progress.md` 4.4.6
