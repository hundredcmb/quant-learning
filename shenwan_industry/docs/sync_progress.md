## 已同步章节明细

### 4.1 基本算法（4.1.1 基本公式 + 4.1.2 连锁法公式）→ 单日自由流通市值加权 ✅

**核对日期**：2026-08-20
**涉及代码**：`shenwan_industry/industry_ranking.py` 的 `daily_rank_float_weight`（`mv_kind="free"`）；`market_data.py`
**对照范围**：只看 4.1（基本公式 + 连锁法公式），**不含** 4.2 以后的任何特殊情况（基期、成份股选择、4.4 各公司行为调整）。

**结论**：在无公司行为 / 无股本变动 / 无除权除息的普通交易日假设下，项目单日自由流通市值加权涨幅与官方 4.1 在**数学上完全等价**，数值上不存在不一致。

官方（4.1.2 连锁法，实际计算采用）：

> I_t = I_{t-1} × (LV_t / LV_{t-1}^{Adj})

即单日涨幅 = LV_t / LV_{t-1}^{Adj} − 1，其中 LV = Σ(自由流通量 × 市价)；无事件时 LV_{t-1}^{Adj} = Σ p_{t-1}·q_{t-1}。

项目（`industry_ranking.py:210-237`）逐股聚合：

> ΔM = M·p/(p+100)；M_pre = M/(1+p/100)；行业涨幅 = ΣΔM / ΣM_pre × 100

等价推导（p = (P_t − P_{t-1}^{adj})/P_{t-1}^{adj}·100 代入）：

> ΔM = (P_t − P_{t-1}^{adj})·q_t、M_pre = P_{t-1}^{adj}·q_t
> ⇒ ΣΔM / ΣM_pre = (LV_t − Σ P_{t-1}^{adj}·q_t) / (Σ P_{t-1}^{adj}·q_t)

普通交易日（无除权、自由流通量不变：P_{t-1}^{adj} = P_{t-1}、q_t = q_{t-1}）恰等于 **LV_t / LV_{t-1} − 1**，与官方 4.1.1 / 4.1.2 一致。

**边界与差异说明（均不构成 4.1 范围内的不一致）**：

1. **产出形态**：官方 4.1 定义指数**点位序列**（定基 + 连锁累乘）；项目只输出**单日涨跌幅**，不做指数连续化（自建行业指数见 `docs/roadmap.md`）。对「单日涨幅榜」而言两者对单日涨跌的定义一致。
2. **分母用哪天的股本**：项目分母固定为「今日自由流通量 × 除权参考价」（由 M/(1+p/100) 反推）；官方无事件分母为「昨日自由流通量 × 昨日收盘价」。股本不变时恒等；一旦 q_t ≠ q_{t-1}（送转 / 配股 / 增发 / 解禁 / 债转股等）即出现差异——**这正是 4.4 各节要处理、当前未同步的部分**，是项目实现与官方唯一的实质分歧源（范围外）。
3. **停牌**：官方 4.4.10 停牌股按停牌前收市价计、分子分母同值（具体规则在 4.4，范围外）；项目「停牌按 0%、分母计入停牌前回退市值」。两者对涨幅的贡献恒等：官方 `(V+A)/(V+B)−1 = A/(V+B)`，项目 `A/(V+B)`。
4. **权重口径**：官方 = 自由流通量 × 市价（自由流通量定义在附录二）；项目 = `free_share × close`（等价于 `circ_mv × free_share / float_share`）。两者同一口径，但附录二对「非自由流通股份」的精确定义无法用 Tushare 黑盒数据逐条核对（见 known_issues 第 18 条，归入未覆盖项）。

### 4.4.1 成份股计入 / 4.4.2 成份股退出 → 单日 / 区间市值加权 ✅（成分历史已接入）

**核对日期**：2026-08-20
**涉及代码**：`industry_tree.py`（`build_constituent_stocks_by_tushare` 拉 Y+N 建 `ts_code_membership`、`filter_stock_pool` 改 membership 过滤、`get_stock_industry_nodes(ts_code, date)` date-aware）；`industry_ranking.py` / `web/service.py`（调用点穿 date）
**数据前提（已实测验证）**：
- `index_member_all` 默认（is_new=Y）=当前成分（out_date 全空），`is_new='N'`=历史退出（100% 带 out_date）；Y+N 并集即每股完整 in/out 区间——实测 **N 的股票集 ⊆ Y**（凡有历史退出的股票现在必属其他行业，申万全样本），故榜单股票池 = `all_member_codes`（当前成分全集）即可，date-aware 过滤即得当日成分。
- 000004.SZ 四段区间：住宅开发(19891223→20081230) / 化学制剂(20081231→20210610) / IT服务Ⅲ(20210611→20210729) / 横向通用软件(20210730→至今)。

**结论**：公式层本就一致（`M/M_pre` 自动把新增/退出成分按 t-1 价回填或前瞻剔除），本次补齐缺失的**成分历史归属**（date-aware），单日榜任意历史日期、区间榜的退出成分均正确；无需改动加权公式。

官方与实现的对应：
- **4.4.1 计入**：官方 `LV_{t-1}^{Adj}` 把新成分按 t-1 价×t-1 量回填基准日。项目：成分自 in_date 进入池，`M_pre = pre_close × 当日 free_share`（普通日=p_{t-1}×q_{t-1}）等价回填；未来纳入（in_date>当日）由 `filter_stock_pool.not_member` 剔除，无前视偏差。
- **4.4.2 退出**：官方当日（从退出日起）分子分母都剔除退出成分（前瞻）。项目：成分 out_date 起不在池中 → 分子分母都不参与；区间模式 `left_mid_range` 把「起始日在但区间末前已调出」的股票剔除（实测：跨 2021-06-11 行业切换的区间 [20210517,20210618] 正确剔除 000004.SZ——其化学制剂区间 20210610 结束）。

边界（见 known_issues 第 23 条）：历史归属按 SW2021 代码口径回填（2021-12-13 版本切换前可能与当时官方版本不完全一致）；区间榜中途换行业仍锚定起始日行业聚合（不按天分段）；市值回退默认回到上市日、不放弃（超长停牌也能解析；旧 730 逻辑经 `SW_MV_RESOLVE_MODE=legacy` 保留，见第 3 条）。

### 4.4.3 新股上市（第6交易日纳入）→ 单日 / 区间市值加权 ✅；公司退市（退市整理期首日口径）✅ 已对照一致（官方成分 out_date 编码，2026-08-24 更新）

**核对日期**：2026-08-21
**涉及代码**：`industry_tree.py` 的 `filter_stock_pool`（`not_listed` 改为「上市未满 6 个交易日」门槛，`_trading_days_window` 用 `trade_cal` 精确计数、实例内窗口缓存）
**数据前提（已实测验证）**：
- 官方：退市 / 进入退市整理期即成分退出（参照 4.4.2）；**新股上市第 6 个交易日才纳入指数**（规避上市初期剧烈动荡）。
- 官方退市退出日为摘牌日或**退市整理期首日**（有整理期时更早数周、整理期末段仍交易）；`stock_basic.delist_date` 只给摘牌日，官方口径由成分 `out_date` 承载（见下「结论」，2026-08-24 更新）。
- 实测新股 `index_member_all` 的 `in_date` 可能**早于上市日**（301655 in_date=20260731 < list=20260820；部分北交所新股无 index_member_all 记录）→ 6 日门槛必须以 `list_date` 为准，不能被 in_date 误导。

**结论**：新股「第 6 个交易日才纳入」已同步（项目原从第 2 交易日计入 → 改从第 6 交易日计入）。
**公司退市已对照一致（2026-08-24 更新，原为有意取舍）**：之前只用了 `stock_basic.delist_date`（摘牌日）兜底、未查官方成分数据；实测 2025-01 以来全部 50 只退市股的 `index_member_all` 记录——**26 只有退市整理期的股票成分 `out_date` 精确 = 整理期首日**（与 `namechange`「XX退」改名日逐一吻合），**19 只无整理期**（创业板/科创板/吸收合并退市）`out_date` = 摘牌日，3 只无成分记录（北交所/数据缺口，`delisted` 按摘牌日兜底）→ 项目 `not_member`（out_date≤当日无归属区间）**在整理期首日起自动剔除**，与官方一致；官方文本"退出日为摘牌日或退市整理期首日"的两种情形均由成分 out_date 精确承载，"整理期首日~摘牌前官方已剔除、项目仍计入"的差异窗口**不存在**（见 known_issues 第 24 条）。

官方与实现的对应：
- **新股上市**：官方第 6 交易日才纳入。项目 `filter_stock_pool.not_listed`：以 `list_date` 起，`[list_date, anchor]` 内交易日数 <6 → 剔除（含未上市），≥6 才参与；快路径——list_date 距锚点超 24 历日的必满 6 交易日直接放行，近窗新股用一次 `trade_cal`（窗口缓存）精确数。验证：301583.SZ（list 20260710）第 1~5 交易日剔除、第 6（20260717）起纳入，老股不受影响。
- **公司退市**：官方退出日 = 摘牌日或**退市整理期首日**，由成分 `out_date` 精确承载——有整理期的（实测 26/50）`out_date`=整理期首日、无整理期的（19/50）=摘牌日 → 项目 `not_member` 在 `out_date` 起自动剔除、`delisted`（`delist_date`=摘牌日）兜底，与官方一致（详见上「结论」段）。

### 4.4.4 送股（转增股）→ 单日自由流通市值加权 ✅

**核对日期**：2026-08-20
**涉及代码**：`industry_ranking.py` 的 `daily_rank_float_weight`（**无特殊分支**，靠 `M=p_t·q_t` 与 `pct=close/pre_close` 口径自洽）；`market_data.py` 的 `get_ts_code_to_pct_chg` / `get_ts_code_to_free_mv`
**数据前提（已实测验证）**：

- `daily_basic` 的 `total_share`/`float_share`/`free_share` 在**除权日（ex_date）当天**即按送转比例更新：301261.SZ 10转2 → `free_share` 精确 ×1.2000；603400.SH 10转3+派0.3 → ×1.294（Tushare 按实际登记股本，非严格 1.3）。
- 除权日 `daily.pre_close` 返回交易所除权参考价（603400 前收 47.28 → 参考价 36.19），`close/pre_close` 即真实涨跌幅（口径见 AGENTS.md 第 3 节）。
- A 股红股上市日（`div_listdate`）＝除权日；扫 2026-06~07 全部除权日，「上市日晚于除权日」样本仅 200028.SZ 且为 **B 股**（不在 A 股 `daily_basic` 覆盖），即官方 4.4.4 的「除权日至上市日 / 上市日」两阶段在项目数据中**不出现**。

**结论**：送转股本身与官方 4.4.4（除权日）一致，无需改代码。

官方（除权日）：LV_{t-1}^{Adj} = Σ p_{t-1}·q_{t-1}（不调整）；LV_t = Σ_{i≠j} p_t·q_t + p_t^j × q_{t-1}^j × (1+m/10)。

项目：M = p_t·q_t（今日股本已含送转）；pct 相对除权参考价；M_pre = M/(1+pct/100) = 除权参考价 × 今日股本。

等价推导：免费送转除权价 p_t = p_{t-1}/(1+m/10)（无真实涨跌时），实证 q_t = q_{t-1}(1+m/10)：

- 官方股票 j 项：p_t × q_{t-1}(1+m/10) = p_{t-1}·q_{t-1}，与 LV_{t-1}^{Adj} 同值 → 送转不干扰指数；
- 项目股票 j 项：M_pre = 除权参考价 × q_t = p_{t-1}·q_{t-1}，无真实涨跌时 ΔM = M − M_pre = 0 → 送转同样价值中性；
- 代入 p_t^j 后，官方 LV_t / LV_{t-1}^{Adj} 与项目 ΣΔM / ΣM_pre 逐项相等（同 4.1 链式等价）。

要点与边界：

- **捆绑派现**（真实送转常含现金分红，如 603400 转3+派0.3）：官方按实际市值走、除息日指数含分红下跌；项目 `pre_close` 已扣减除息，除息当日按真实涨跌计、现金分红不计入收益——此为项目既有的除权参考价（复权/全收益式）口径（AGENTS.md 第 3 节、known_issues #10/#11），非本次送转逻辑引入。
  - **（2026-08-21/23 更新）单日榜自由流通/总市值加权与等权均已拆分两种口径**：官方价格式（`div_kind="price"`，默认，除息计入下跌）与分红再投资/全收益式（`"reinvest"`，除息中性）——规则见 `shenwan_industry/AGENTS.md` 第 4/5 节、`known_issues.md` 第 30 条（除息日 `M_pre` 用昨日实际市值，纯除息 301586/301559、捆绑送转+派现 603400（两日股本 2800→3623）均数值校验与官方公式严格一致；Web 下拉可选）。**同日更新：官方逐日链式区间榜已实现**（`rank_range_chain`：逐日再平衡链、6 条序列、Web 默认/静态版对照；实现与实测对照全部见下方「区间累计涨幅榜」小节与 known_issues 第 32 条）。
- 「除权日至上市日 / 上市日」两阶段：为「股本数据滞后于除权日」的历史情景设计，A 股数据不出现（股本在除权日即更新、红股上市日=除权日），项目无需实现；若未来出现 A 股晚上市样本需再评估股本更新时点（见 known_issues 第 20 条）。
- 区间榜：个股收益用逐日 `close/pre_close` 连乘（送转日按 0% 累计）、权重锚定区间起始日自由流通市值（不受除权日股本放大影响），同理一致。

### 4.4.5 配股 → 单日 / 区间市值加权 ✅（pre_close 自动处理，德赛实测）

**核对日期**：2026-08-21
**涉及代码**：无（靠 `daily.pre_close` 配股除权参考价 + `free_share` 自动自洽）
**数据前提（已实测验证，德赛电池 000049.SZ 2023 配股）**：
- 关键日期：股权登记日 2023-11-29（收 31.54）→ 缴款期 11-30~12-06（daily 无行）→ **复牌除权日 12-08 pre_close=29.24** → 配售股份上市日 12-25。
- `daily.pre_close`（12-08）= 配股除权参考价，与官方公式吻合：反推 10 配约 2.85、配股价约 21.2 元，`(31.54 + 21.2×0.2847)/(1+0.2847) = 29.24` ✓。
- 股本演进（daily_basic）：`total_share` 12-08 即 29939→38464（总股本已含配股）；`float_share` 12-25 才 29928→38453（上市流通）；**`free_share` 全程恒定 20955.1**——配股新股几乎全给控股方，按附录二属非自由流通，不进自由流通量。

**结论**：配股无需改代码。单股涨跌幅口径自动一致：
- 设配股 m/10、配股价 p_SEO，`P_ref = (p_{t-1} + p_SEO·m/10)/(1+m/10)`（= Tushare pre_close，实测德赛吻合）。官方 4.4.5 除权日股票 j 的 `LV_t/LV_{t-1}^{Adj} − 1 = p_t/P_ref − 1`；项目 `ΔM/M_pre = (p_t − P_ref)/P_ref`——q 在分子分母抵消，两者恒等，配股各阶段（除权日/缴款期/上市日）均退化为 `p_t/P_ref` 或 `p_t/p_{t-1}`。
- **权重层 = 官方文本与附录二的内在张力**：官方 4.4.5 文本对自由流通量机械 ×(1+m/10)，而配股新股落在控股方时（德赛即如此）按附录二应扣减、不属于自由流通量；项目锚定 Tushare `free_share`（附录二扣减后的真实自由流通量），反而自洽。
- 次级边界：若配股新股真属自由流通，`free_share` 在上市日（或除权日）更新，项目随之计入；`free_share` 未在除权日含新股本时（德赛即如此），与官方「除权日即按 (1+m/10) 计入权重」差一个缴款期窗口，配股罕见、影响可忽略（见 known_issues 第 25 条）。

### 4.4.10 公司停牌（一般停牌）→ 单日自由流通市值加权 ✅

**结论**：一般停牌处理与官方 4.4.10 一致。

官方（一般停牌）：停牌日**无须调整**前一交易日市值（LV_{t-1}^{Adj} 照常、不剔除停牌股），停牌股按**前一交易日收市价**计入当日市值（LV_t 中 = p_{t-1}·q_{t-1}，自由流通量不变）。

其余要点：

- 回退的 M 即停牌前最近（有效）自由流通市值 = p_{t-1}'·q_{t-1}'，与官方「自由流通量不变、按前一交易日收市价」一致（停牌期间无股本变动时）。
- 停牌期间发生除权除息：官方一般停牌在停牌日仍以停牌前收市价计、不调整；项目回退同样不调整，除权影响在复牌日由 `pre_close`（除权参考价）体现（见 `known_issues.md` 第 11 条），一致。
- **股改复牌**：已由官方成分断点自动覆盖（断点即"是否股改"的标识，无需区分停牌原因），见 4.4.9/4.4.10 小节与 `known_issues.md` 第 19 条。

**数据前提（已实测验证）**：

- `share_float` 给出限售股解禁的 `ann_date`（公告日）与 `float_date`（上市流通日）；扫 2026-06~07 全部 **72,565 条解禁记录，100% 为 `ann_date < float_date`（先公告后上市，规则①）**，0 条规则②型。
- 301503.SZ 0717 解禁 9504 万股：`float_share` +1188 万股但 **`free_share` 不变**——解禁给大股东时按附录二扣减仍属非自由流通，free_share 不上涨（与官方同锚点，不能拿解禁量直接加进 q，只能以 free_share 实际变化为准）。
- 300806.SZ 0717 `free_share` 突跳并非 share_float 解禁（当天 36 条解禁无它）——存在 share_float 之外的非解禁股本变动（债转股/激励行权等），无统一接口查其公告日/上市日。

**结论**：市值调整公式与规则①（上市日记入）一致，无需改代码；规则②（公告日+4交易日）为 ⏳ 已知边界——公式层与官方一致、仅 q 生效时点取数据报告日近似（详见下）。

官方（市值调整公式）：计入日 t，`LV_{t-1}^{Adj}` 中股票 j 项 = `p_{t-1}^j × q_t^j`（t-1 价 × t 日新股本，把新增自由流通量价值回填进分母，避免上市流通日虚假跳涨）；`LV_t` = Σ p_t·q_t。

项目：`M = p_t·q_t`、`M_pre = M/(1+pct/100) = 除权参考价 × 当日 free_share`；普通日（无除权）`pre_close = p_{t-1}` → `M_pre = p_{t-1} × q_t` ≡ 官方 `LV_{t-1}^{Adj}` 项、`M = p_t·q_t` ≡ 官方 `LV_t` 项。任何一天 free_share 变大（自由流通量增加），新股本自动按 t-1 价回填分母、价值中性——与 4.4.4/4.4.10 同一机制，公式层零改动。

计入时间对齐：

- **规则①（上市日计入）**：项目以 `free_share` 实际更新日为准，而 free_share 在上巿流通日更新 → 一致；
- **规则②（公告日+4交易日）已知边界（2026-08-24 更新定位）**：债转股/权证行权/定向回购这类"上市自由流通后才公告"的事件，官方自**股本变动公告日（非交易日顺延）第 4 个交易日**起将新增自由流通量计入权重（前置于实际上市流通日）。**公式层项目与官方一致**——官方调整公式 `LV_{t-1}^{Adj}(j)=p_{t-1}×q_t`、`LV_t(j)=p_t×q_t` 与项目 `M_pre=pre_close×q_t`、`M=p_t×q_t` 在普通日（不除权）逐项恒等（与规则①同一公式，已对照）；**唯一差异 = q 生效时点**：官方按公告日+4交易日提前使用新 q，项目按 Tushare `daily_basic` 数据实际报告日（可能滞后数日）→ 时点近似边界（与 4.4.6 债转股同构；此类事件股本变动幅度小、权重影响可忽略，不重建公告日序列）。`share_float` 不覆盖这些事件类型且实测 0 条规则②型；**与官方存在时点差异，故仍记 ⏳ 已知边界**（见 known_issues 第 22 条）。

### 区间累计涨幅榜（官方逐日链式区间榜 `rank_range_chain`）→ 区间市值加权 ✅

**核对日期**：2026-08-23（实现与实测对照 2026-08-21/23）
**涉及代码**：`industry_ranking.py` 的 `rank_range_chain`（每日再平衡链）；`market_data.py`（行情/市值/除息三池并行预取、日历切片缓存、停牌跨日复用 memo）；`web/service.py`（Web 默认 `chain=true`）、`range_ranking.py`（CLI 链式+静态双输出对照）
**对照对象**：官方指数为逐日点位序列（4.1.2 连锁法累乘），其**区间涨幅 = 期末点位 / 期初基准点位 − 1 = 逐日涨幅连乘**；官方文本无显式「区间累计」公式，故以「申万官方指数实盘区间涨幅」为比照基准（AGENTS.md 第 7.2 节）。

**结论**：链式区间榜与官方一致；原静态版（锚定起始日）保留为对照模式（仅 API `chain=false` / CLI 可见）。

- **公式层**：`rank_range_chain` 每个交易日按**当日**成分（逐日过滤，新股纳入/退市即单日榜口径）与当日盘前市值权重逐日计算，复用单日榜同款日级函数，逐行业连乘 `Π(1+pct/100)`——链式单日区间 ≡ 单日榜逐行业零差异，而单日榜已对照 4.1/4.4 各节一致，故区间公式层与官方逐日链严格一致。
- **官方价格式已覆盖区间榜**：链式版输出 6 条序列（等权/自由流通/总市值 × 官方价格式/全收益式），原「区间榜仍全收益式」未覆盖项随链式版落地而消除；仅**静态版仍全收益式**（对照模式，不声称与官方同步）。
- **实测对照**（2024-09-24~2024-12-31，66 交易日）：31/31 行业与申万官方 L1 指数区间涨幅平均差 **0.44pp**、最大 1.09pp（计算机），方向/量级一致；残差全部落在 Tushare 自由流通口径 vs 官方附录二扣减明细（known_issues 第 18 条）已知范围内，**逐日公式本身与官方一致**。
