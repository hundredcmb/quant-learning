### 4.1 基本算法（4.1.1 基本公式 + 4.1.2 连锁法公式）→ 单日自由流通市值加权 ✅

**核对日期**：2026-08-20
**涉及代码**：`shenwan_industry/industry_ranking.py` 的 `daily_rank_float_weight`（`mv_kind="free"`）；`market_data.py`
**对照范围**：只看 4.1（基本公式 + 连锁法公式），**不含** 4.2 以后的任何特殊情况（基期、成份股选择、4.4 各公司行为调整）。

**结论**：在无公司行为 / 无股本变动 / 无除权除息的普通交易日假设下，项目单日自由流通市值加权涨幅与官方 4.1 在**数学上完全等价**，数值上不存在不一致。

官方（4.1.2 连锁法，实际计算采用）：

> I_t = I_{t-1} × (LV_t / LV_{t-1}^{Adj})

即单日涨幅 = LV_t / LV_{t-1}^{Adj} − 1，其中 LV = Σ(自由流通量 × 市价)；无事件时 LV_{t-1}^{Adj} = Σ p_{t-1}·q_{t-1}。

项目（`industry_ranking.py:210-237`）逐股聚合：

> ΔM = M·p/(p+100)；M_pre = M/(1+p/100)；行业涨幅 = ΣΔM / ΣM_pre × 100

等价推导（p = (P_t − P_{t-1}^{adj})/P_{t-1}^{adj}·100 代入）：

> ΔM = (P_t − P_{t-1}^{adj})·q_t、M_pre = P_{t-1}^{adj}·q_t
> ⇒ ΣΔM / ΣM_pre = (LV_t − Σ P_{t-1}^{adj}·q_t) / (Σ P_{t-1}^{adj}·q_t)

普通交易日（无除权、自由流通量不变：P_{t-1}^{adj} = P_{t-1}、q_t = q_{t-1}）恰等于 **LV_t / LV_{t-1} − 1**，与官方 4.1.1 / 4.1.2 一致。

**边界与差异说明（均不构成 4.1 范围内的不一致）**：

1. **产出形态**：官方 4.1 定义指数**点位序列**（定基 + 连锁累乘）；项目只输出**单日涨跌幅**，不做指数连续化（自建行业指数见 `docs/roadmap.md`）。对「单日涨幅榜」而言两者对单日涨跌的定义一致。
2. **分母用哪天的股本**：项目分母固定为「今日自由流通量 × 除权参考价」（由 M/(1+p/100) 反推）；官方无事件分母为「昨日自由流通量 × 昨日收盘价」。股本不变时恒等；一旦 q_t ≠ q_{t-1}（送转 / 配股 / 增发 / 解禁 / 债转股等）即出现差异——**这正是 4.4 各节要处理、当前未同步的部分**，是项目实现与官方唯一的实质分歧源（范围外）。
3. **停牌**：官方 4.4.10 停牌股按停牌前收市价计、分子分母同值（具体规则在 4.4，范围外）；项目「停牌按 0%、分母计入停牌前回退市值」。两者对涨幅的贡献恒等：官方 `(V+A)/(V+B)−1 = A/(V+B)`，项目 `A/(V+B)`。
4. **权重口径**：官方 = 自由流通量 × 市价（自由流通量定义在附录二）；项目 = `free_share × close`（等价于 `circ_mv × free_share / float_share`）。两者同一口径，但附录二对「非自由流通股份」的精确定义无法用 Tushare 黑盒数据逐条核对（见 known_issues 第 18 条，归入未覆盖项）。

### 4.4.10 公司停牌（一般停牌）→ 单日自由流通市值加权 ✅

**核对日期**：2026-08-20
**涉及代码**：`industry_ranking.py` 的 `daily_rank_float_weight`（停牌处理 `industry_ranking.py:207-227`）；`market_data.py` 的 `get_ts_code_to_free_mv` / `resolve_free_mv`（停牌 730 天回退）
**对照假设**：Tushare 无法区分停牌是否属股改；2010 年后股改基本完毕，**所有停牌一律按一般停牌处理**，不实现「股改公司复牌」特殊规则。

**结论**：一般停牌处理与官方 4.4.10 一致。

官方（一般停牌）：停牌日**无须调整**前一交易日市值（LV_{t-1}^{Adj} 照常、不剔除停牌股），停牌股按**前一交易日收市价**计入当日市值（LV_t 中 = p_{t-1}·q_{t-1}，自由流通量不变）。

项目：停牌股 `daily` 无记录 → 涨幅按 0%（`pct=0`）→ ΔM=0（不贡献分子）；自由流通市值经 730 天回退取「停牌前最近有效值」M 作 M_pre 计入分母（稀释）。

一致性验证（沿用 4.1 恒等推导）：官方比值 = (V+A)/(V+B)（停牌股市值 V 分子分母同值），项目 = A/(V+B)（分子 ΣΔM 不含 V、分母含 V），两者单日涨幅均为 A/(V+B)×100，恒等。（V=停牌股回退市值；A=其余股票当日新增市值和；B=其余股票开盘前市值和）

其余要点：

- 回退的 M 即停牌前最近（有效）自由流通市值 = p_{t-1}'·q_{t-1}'，与官方「自由流通量不变、按前一交易日收市价」一致（停牌期间无股本变动时）。
- 停牌期间发生除权除息：官方一般停牌在停牌日仍以停牌前收市价计、不调整；项目回退同样不调整，除权影响在复牌日由 `pre_close`（除权参考价）体现（见 `known_issues.md` 第 11 条），一致。
- **股改复牌（复牌首日退出指数、复牌后第 2 个交易日重新计入）：未实现**——Tushare 无法标识股改停牌，按以上假设全部视为一般停牌（2010 年后影响基本为零），见 `known_issues.md` 第 19 条。

### 4.4.4 送股（转增股）→ 单日自由流通市值加权 ✅

**核对日期**：2026-08-20
**涉及代码**：`industry_ranking.py` 的 `daily_rank_float_weight`（**无特殊分支**，靠 `M=p_t·q_t` 与 `pct=close/pre_close` 口径自洽）；`market_data.py` 的 `get_ts_code_to_pct_chg` / `get_ts_code_to_free_mv`
**数据前提（已实测验证）**：

- `daily_basic` 的 `total_share`/`float_share`/`free_share` 在**除权日（ex_date）当天**即按送转比例更新：301261.SZ 10转2 → `free_share` 精确 ×1.2000；603400.SH 10转3+派0.3 → ×1.294（Tushare 按实际登记股本，非严格 1.3）。
- 除权日 `daily.pre_close` 返回交易所除权参考价（603400 前收 47.28 → 参考价 36.19），`close/pre_close` 即真实涨跌幅（口径见 AGENTS.md 第 3 节）。
- A 股红股上市日（`div_listdate`）＝除权日；扫 2026-06~07 全部除权日，「上市日晚于除权日」样本仅 200028.SZ 且为 **B 股**（不在 A 股 `daily_basic` 覆盖），即官方 4.4.4 的「除权日至上市日 / 上市日」两阶段在项目数据中**不出现**。

**结论**：送转股本身与官方 4.4.4（除权日）一致，无需改代码。

官方（除权日）：LV_{t-1}^{Adj} = Σ p_{t-1}·q_{t-1}（不调整）；LV_t = Σ_{i≠j} p_t·q_t + p_t^j × q_{t-1}^j × (1+m/10)。

项目：M = p_t·q_t（今日股本已含送转）；pct 相对除权参考价；M_pre = M/(1+pct/100) = 除权参考价 × 今日股本。

等价推导：免费送转除权价 p_t = p_{t-1}/(1+m/10)（无真实涨跌时），实证 q_t = q_{t-1}(1+m/10)：

- 官方股票 j 项：p_t × q_{t-1}(1+m/10) = p_{t-1}·q_{t-1}，与 LV_{t-1}^{Adj} 同值 → 送转不干扰指数；
- 项目股票 j 项：M_pre = 除权参考价 × q_t = p_{t-1}·q_{t-1}，无真实涨跌时 ΔM = M − M_pre = 0 → 送转同样价值中性；
- 代入 p_t^j 后，官方 LV_t / LV_{t-1}^{Adj} 与项目 ΣΔM / ΣM_pre 逐项相等（同 4.1 链式等价）。

要点与边界：

- **捆绑派现**（真实送转常含现金分红，如 603400 转3+派0.3）：官方按实际市值走、除息日指数含分红下跌；项目 `pre_close` 已扣减除息，除息当日按真实涨跌计、现金分红不计入收益——此为项目既有价格指数口径（AGENTS.md 第 3 节、known_issues #10/#11），非本次送转逻辑引入；是否要与官方对齐「派现下跌」另行决策（列入未覆盖项）。
- 「除权日至上市日 / 上市日」两阶段：为「股本数据滞后于除权日」的历史情景设计，A 股数据不出现（股本在除权日即更新、红股上市日=除权日），项目无需实现；若未来出现 A 股晚上市样本需再评估股本更新时点（见 known_issues 第 20 条）。
- 区间榜：个股收益用逐日 `close/pre_close` 连乘（送转日按 0% 累计）、权重锚定区间起始日自由流通市值（不受除权日股本放大影响），同理一致。

### 4.4.13 非自由流通股上市流通 → 单日自由流通市值加权 ✅（市值调整公式 + 规则①；规则② 有意取舍）

**核对日期**：2026-08-20
**涉及代码**：`industry_ranking.py` 的 `daily_rank_float_weight`（无新增分支，靠 `M/M_pre` 自洽）；`market_data.py` 的 `get_ts_code_to_free_mv`
**数据前提（已实测验证）**：

- `share_float` 给出限售股解禁的 `ann_date`（公告日）与 `float_date`（上市流通日）；扫 2026-06~07 全部 **72,565 条解禁记录，100% 为 `ann_date < float_date`（先公告后上市，规则①）**，0 条规则②型。
- 301503.SZ 0717 解禁 9504 万股：`float_share` +1188 万股但 **`free_share` 不变**——解禁给大股东时按附录二扣减仍属非自由流通，free_share 不上涨（与官方同锚点，不能拿解禁量直接加进 q，只能以 free_share 实际变化为准）。
- 300806.SZ 0717 `free_share` 突跳并非 share_float 解禁（当天 36 条解禁无它）——存在 share_float 之外的非解禁股本变动（债转股/激励行权等），无统一接口查其公告日/上市日。

**结论**：市值调整公式与规则①（上市日记入）一致，无需改代码；规则②（公告日+4交易日）有意取舍不实现。

官方（市值调整公式）：计入日 t，`LV_{t-1}^{Adj}` 中股票 j 项 = `p_{t-1}^j × q_t^j`（t-1 价 × t 日新股本，把新增自由流通量价值回填进分母，避免上市流通日虚假跳涨）；`LV_t` = Σ p_t·q_t。

项目：`M = p_t·q_t`、`M_pre = M/(1+pct/100) = 除权参考价 × 当日 free_share`；普通日（无除权）`pre_close = p_{t-1}` → `M_pre = p_{t-1} × q_t` ≡ 官方 `LV_{t-1}^{Adj}` 项、`M = p_t·q_t` ≡ 官方 `LV_t` 项。任何一天 free_share 变大（自由流通量增加），新股本自动按 t-1 价回填分母、价值中性——与 4.4.4/4.4.10 同一机制，公式层零改动。

计入时间对齐：

- **规则①（上市日计入）**：项目以 `free_share` 实际更新日为准，而 free_share 在上巿流通日更新 → 一致；
- **规则②（公告日+4交易日）**：债转股/权证行权/定向回购需在「上市流通日→公告日+4交易日」窗口冻结旧股本。`share_float` 不覆盖这些事件类型，且其解禁域内实测 0 条规则②型 → **无法完整实现，有意取舍不实现**（类同 4.4.10 股改取舍，见 known_issues 第 22 条）。
